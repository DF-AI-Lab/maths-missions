## Prototypes / tests
- **Garden Mission v0** (index.html, also at https://claude.ai/artifact/3oMVfwG8DeBc5WMwHNVB3E)
  - 13 jobs: lawn area, reverse check, pond (circle), fraction, turf, cost, % sale, fence, panels, volume, litres, ratio, averages
  - Answers chain via a notebook. New random numbers each game (π = 3, non-calc friendly)
  - Forced double check: tick all "Before you check" boxes to unlock Check; ticks clear after a wrong try
  - Wrong once → targeted slip hint. Wrong twice → worked answer, mission carries on with the right value
  - Unit picker (m, m², m³ / ml, litres) to catch unit slips
  - Results: first time / caught / shown, slip tally, past missions (stored on the device)
  - Responsive, so it doubles as the mobile version for now
